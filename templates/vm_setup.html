VM Setup Instructions

🟥 Red Team (Kali Linux)

  • Download Kali ISO from official site
  • Create VM in VirtualBox, allocate 2GB RAM
  • Attach ISO and install Kali
  • Set network adapter to Host-only

🟦 Blue Team (Ubuntu)

  • Download Ubuntu Desktop (22.04 or 24.04)
  • Create VM in VirtualBox, allocate 2GB RAM
  • Set up basic services like UFW, Fail2Ban, Wireshark
  • Install tools like Logwatch or OSSEC

🪓 Victim (Metasploitable2)

  • Download OVA from trusted GitHub archives
  • Import into VirtualBox
  • Use Host-only Adapter
  • Check IP using `ifconfig` or `ip a`

📡 Connect the Network

  • All machines should be on Host-only adapter like `vboxnet0`
  • Ping across VMs to test connectivity
